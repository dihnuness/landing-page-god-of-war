# God of War — Landing Page

Projeto educacional não oficial de Diogo Nunes, inspirado na página da PlayStation, criado para praticar desenvolvimento front-end. Não possui vínculo com Sony ou Santa Monica Studio.

## Histórico
desenvolvi de 2023 a 2025, conforme adiquiria experiência.

## Tecnologias
HTML5, CSS3 (Flexbox, Grid e media queries) e JavaScript.

## Funcionalidades
- Layout responsivo para desktop, tablet e celular.
- Menu móvel com controle de teclado e estado acessível.
- Trailer incorporado com proporção adaptável.
- Catálogo de oito jogos com imagens em suas proporções originais.
- Links para o portal oficial da franquia e perfis profissionais.

## Executar
Abra `index.html` no navegador ou utilize Live Server. Para GitHub Pages, publique a pasta que contém `index.html` na raiz do repositório ou da origem configurada. Os caminhos são relativos. O trailer, fontes externas e links precisam de internet.

## Direitos
Marcas, imagens, fontes e vídeo pertencem aos respectivos titulares. Verifique as licenças e permissões dos recursos originais antes da publicação pública. Não há vendas ou vínculo oficial com a franquia.
